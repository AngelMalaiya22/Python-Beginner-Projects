# Password Generator

## Overview

A simple Python application that generates a secure random password based on the user-specified length. The password includes uppercase letters, lowercase letters, numbers, and special characters.

## Features

* Generate passwords of any length
* Includes letters, digits, and special characters
* Random and secure password generation
* Easy to use

## Technologies Used

* Python
* Random module
* String module

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Enter the desired password length.
4. The generated password will be displayed.
