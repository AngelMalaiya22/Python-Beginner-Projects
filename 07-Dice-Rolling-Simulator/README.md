# Dice Rolling Simulator

## Overview

A simple Python program that simulates rolling a six-sided dice. The user can roll the dice multiple times, and each roll generates a random number between 1 and 6.

## Features

* Simulates a six-sided dice roll
* Generates random outcomes
* Allows multiple rolls
* Simple and interactive interface

## Technologies Used

* Python
* Random module

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Press **Enter** to roll the dice.
4. Choose whether to roll again.
