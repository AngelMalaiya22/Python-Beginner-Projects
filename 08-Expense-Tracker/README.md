# Expense Tracker

## Overview

A simple Python Expense Tracker that helps users record and manage their daily expenses. Users can add expenses, view all recorded expenses, and calculate the total amount spent.

## Features

* Add new expenses
* View all recorded expenses
* Calculate total expenses
* Menu-driven interface
* Beginner-friendly implementation

## Technologies Used

* Python

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Choose an option from the menu.
4. Add and manage your expenses.
