# To-Do List

## Overview

A simple Python To-Do List application that allows users to manage their daily tasks. Users can add new tasks, view all tasks, remove completed tasks, and exit the program.

## Features

* Add new tasks
* View all tasks
* Remove tasks by number
* Interactive menu-driven interface
* Beginner-friendly implementation

## Technologies Used

* Python

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Choose an option from the menu.
4. Add, view, or remove tasks as needed.
