# Temperature Converter

## Overview

A simple Python program that converts temperatures between Celsius and Fahrenheit. The user can choose the conversion type and enter the temperature value to get the converted result.

## Features

* Convert Celsius to Fahrenheit
* Convert Fahrenheit to Celsius
* User-friendly menu
* Input validation for conversion choice

## Technologies Used

* Python

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Select the conversion type.
4. Enter the temperature value to view the converted result.
