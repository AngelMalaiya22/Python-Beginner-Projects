# Rock Paper Scissors

## Overview

A simple Python implementation of the classic Rock Paper Scissors game where the user competes against the computer. The computer makes a random choice, and the winner is determined based on the game rules.

## Features

* Play against the computer
* Random computer choices
* Win, lose, or tie detection
* Option to play multiple rounds
* Input validation for user choices

## Technologies Used

* Python
* Random module

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Enter **Rock**, **Paper**, or **Scissors** when prompted.
4. Choose whether to play another round after each game.
