# Number Guessing Game

## Overview

A simple Python game where the player tries to guess a randomly generated number between 1 and 100. The game provides hints after each guess until the correct number is guessed.

## Features

* Random number generation
* Unlimited guessing attempts
* Hints for high and low guesses
* Displays the total number of attempts

## Technologies Used

* Python
* Random module

## How to Run

1. Open the Jupyter Notebook.
2. Run the code cell.
3. Enter your guesses when prompted.
4. Continue until you guess the correct number.
